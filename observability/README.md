# Observability Stack

Configuration of metrics, logs, and distributed tracing
for the microservices application.

## Components
- Prometheus: Metrics collection and querying.
- Grafana: Metrics visualization and dashboards.
- Loki: Log storage and querying.
- Promtail: Log collection and shipping.
- Jaeger: Distributed tracing.

## Responsibilities
- Deploy and validate the observability components.
- Verify that telemetry is collected correctly.
- Establish a steady-state performance baseline.
- Document queries, configurations, and troubleshooting.
