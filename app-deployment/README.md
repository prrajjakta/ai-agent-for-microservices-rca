# Application Deployment

Deployment of Google's Online Boutique microservices application
and configuration of Locust for traffic generation.

## Responsibilities
- Deploy Online Boutique to the shared Kubernetes cluster.
- Verify that all 11 microservices are healthy.
- Map the service dependency graph.
- Create Locust scripts for browsing, viewing items,
  and adding items to the cart.
- Document deployment and traffic-generation procedures.
