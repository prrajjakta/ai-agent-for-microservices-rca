# Chaos Engineering and Fault Injection

Controlled fault injection using Chaos Mesh to evaluate
root cause analysis in microservice-based cloud systems.

## Planned Fault Types
- NetworkChaos: Network delay and packet loss.
- StressChaos: CPU and memory stress.
- PodChaos: Pod termination.

## Responsibilities
- Configure and validate Chaos Mesh.
- Create reusable fault-injection templates.
- Implement inject.py to automate fault experiments.
- Record ground-truth labels and fault timestamps in CSV.
- Verify fault cleanup and service recovery.
